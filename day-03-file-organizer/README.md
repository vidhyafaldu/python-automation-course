# Day 03 – Automatic File Organizer using Python

## 📌 Project Overview

The Automatic File Organizer is a Python automation project that organizes files into separate folders based on their file extensions.

Instead of manually organizing files, Python automatically identifies file types and moves them into their respective folders.

## 🎯 Objectives

- Learn Python file and folder automation.
- Understand file extensions.
- Create folders automatically.
- Move files using Python.
- Prevent duplicate filename overwrites.
- Generate an organization summary.

## 🛠️ Technologies Used

- Python 3
- pathlib
- os
- shutil
- collections

## 📂 Project Structure

```text
day-03-file-organizer/
│

│
└── organized_files/
    ├── Images/
    ├── PDFs/
    ├── Text/
    ├── Spreadsheets/
    ├── Documents/
    ├── Python/
    └── Others/
```

## ⚙️ Features

1. Automatically identifies file extensions.
2. Creates folders based on file categories.
3. Moves files into appropriate folders.
4. Handles unknown file types.
5. Prevents overwriting files with duplicate names.
6. Displays a summary of organized files.

## 📁 Supported File Types

| Category | Extensions |
|---|---|
| Images | jpg, jpeg, png, gif |
| PDFs | pdf |
| Text | txt |
| Spreadsheets | csv, xlsx |
| Documents | docx, doc |
| Python | py |
| Others | Unsupported extensions |

## ▶️ How to Run

**Step 1:** Clone the repository or download the project.

**Step 2:** Open the project folder in VS Code.

**Step 3:** Add sample files inside the `sample_files` folder.

**Step 4:** Run the following command:

```bash
python organizer.py
```

**Step 5:** Check the `organized_files` folder for organized files.
